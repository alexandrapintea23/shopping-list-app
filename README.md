# shopping - list - app

Simple shopping list mobile application created with MIT App Inventor

A mobile shopping list application developed with MIT App Inventor during my first year of university.

The application allows users to create and manage a shopping list, store data locally using TinyDB, browse products and access several interactive features through a multi-screen interface.

## Features

- User authentication
- Add and remove products from the shopping list
- Local data storage using TinyDB
- Shopping list export
- Product suggestions
- Fruit and vegetable store section
- Store location and opening hours
- Phone call functionality
- Dark and light mode
- Application rating system
- Sound effects and animations
- Interactive notifications and confirmations

## Technologies

- MIT App Inventor
- TinyDB

## How to Run

1. Download the `.aia` project file from this repository.
2. Open MIT App Inventor and import the project using `Projects > Import project (.aia) from my computer`.
3. Install the MIT AI2 Companion app on your phone.
4. In MIT App Inventor, select `Connect > AI Companion`.
5. Scan the generated QR code with the MIT AI2 Companion app.
6. The application will open on your phone for testing.
